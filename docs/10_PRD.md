# 第十部分 PRD

## 1. 产品定义

产品名称：AI 智能选股策略编译器。  
目标用户：具备基础 A 股分析常识、能描述选股判断但不擅长配置条件的个人投资者。  
核心任务：把“经营改善、估值合理、走势稳定”等自然语言，转成用户可检查、可修改、可执行并可追溯的筛选策略。

产品输出是“与用户确认策略的匹配情况”，不是投资建议。任何结果都要展示其数据来源、时点、单位、统计口径和证据状态。

## 2. 目标与范围

| 类型 | 内容 | 验收标准 |
| --- | --- | --- |
| 产品目标 | 降低策略配置成本 | 20 名目标用户中至少 14 名在无人工提示下完成指定主链路；成功用户中位时长不超过 5 分钟 |
| 产品目标 | 保证执行可信 | 随机抽取 100 条条件判断，Evidence 11 个必填字段完整率为 100% |
| 产品目标 | 支持连续迭代 | 50 条预标注 Patch 中 50 条只修改用户指定字段；未确认 Patch 写入次数为 0 |
| P0 范围 | 指数股票池、利润增长、PE-TTM、60 日波动率、候选事实对比与研究交接 | 50 次真实确认后执行中成功次数至少 47 次，P95 端到端时长不超过 60 秒 |
| P1 范围 | 行业/板块消歧、iFinD 研究增强、策略保存 | 扶摇 P0 数据闭环和成本门槛通过后才接入 |
| 非目标 | 下单、荐股、收益预测、全量回测平台 | UI 和 Agent 均不得暗示上述能力 |

## 3. 核心对象

### 3.1 Strategy State

Strategy State 是唯一可执行的策略版本，包含 `strategy_id`、`version`、`universe`、`conditions`、`as_of`、`status` 和审计信息。草稿可被编辑；只有 `CONFIRMED` 版本可被执行。

### 3.2 Evidence

Evidence 绑定“规则结果”和“原始事实”。每条记录至少包含：`metric`、`raw_value`、`computed_value`、`operator`、`threshold`、`result`、`source`、`as_of`、`period`、`unit`、`formula` 和 `quality_status`。

### 3.3 Result Row

一只标的在每个条件下拥有 `PASS`、`FAIL` 或 `UNKNOWN`。只有所有必填条件均为 `PASS` 才进入候选；`UNKNOWN` 不能被计算为 `FAIL`。

## 4. 主流程

| 步骤 | 用户动作 | 系统动作 | 可见产物 | 退出条件 |
| --- | --- | --- | --- | --- |
| 1 表达 | 输入自然语言 | Intent Parser 提取任务和条件线索 | 原始表达 | 输入非空 |
| 2 消歧 | 选择候选实体或补充信息 | Entity Resolver 解析股票池 | Universe | 仅一个可执行实体 |
| 3 编译 | 查看建议并修改 | Compiler 生成草稿，Validator 校验 | Draft Strategy | 不存在阻断错误 |
| 4 确认 | 点击确认 | 锁定版本与参数 | Confirmed Strategy | 用户确认 |
| 5 执行 | 等待或重试 | Tool Router、质量闸门、计算和规则引擎运行 | 漏斗、结果矩阵 | 执行结束或错误 |
| 6 解释 | 展开股票或条件 | Evidence Builder、Explanation Agent 输出受证据约束的说明 | Evidence Drawer | 用户关闭或继续修改 |
| 7 修改 | 输入自然语言修改 | Patch Agent 生成前后差异 | Patch Preview | 用户确认或取消 |

## 5. 功能需求

| ID | 功能 | 需求 | 验收 |
| --- | --- | --- | --- |
| F01 | 策略输入 | 支持一句自然语言输入与示例填充 | 输入被完整保留并可回看 |
| F02 | 理解与消歧 | 显示识别出的股票池、条件、假设和不确定项 | 不能静默把多义实体或指标转为规则 |
| F03 | 策略确认 | 条件可增删改；执行按钮仅在全部 P0 条件有效时可用 | 确认前不得调用最终筛选 |
| F04 | 确定性筛选 | 以已确认 Strategy State 和金融工具数据筛选 | 条件判断不经过 LLM 决策 |
| F05 | 结果解释 | 显示漏斗、结果矩阵、来源、时点、口径、公式 | 每个 PASS/FAIL/UNKNOWN 都可展开证据 |
| F06 | 自然语言修改 | 生成 JSON Patch 预览，显示改变和保留项 | 未确认 Patch 不影响当前已执行版本 |
| F07 | 异常呈现 | 区分未知、过期、冲突、数据错误和工具错误 | 失败标的不被误标为不满足 |
| F08 | 候选对比与研究交接 | 最多选择 3 个标的，对比同口径 Evidence，并显示数据缺口和事实型研究问题 | 不可比数据标为 `NOT_COMPARABLE`；不得生成排名、预测或交易指令 |
| F09 | iFinD 研究增强 | 对候选集合按需调用 iFinD 获取事件/资讯/行业语境 | 仅在扶摇 P0 闭环通过后接入；研究内容与筛选事实分区展示 |

## 6. 业务规则

1. 只有已解析且已确认的 Universe 才可执行。
2. 只能使用 Metric Registry 中标记为 `executable` 的指标；无映射指标返回 `UNSUPPORTED`。
3. “增长快”“估值合理”“稳定”等无统一阈值的描述必须在草稿中作为建议和待确认项，不能直接当作最终条件。
4. `null`、空数组、无有效报告期或无法计算的派生指标统一为 `UNKNOWN`。
5. 数据时间超过指标的新鲜度阈值时标为 `STALE`；不能在“最新”视图中当作有效现值。
6. 同一指标存在不可比口径、单位或来源冲突时标为 `CONFLICT`；不得自动挑选数值。
7. 核心条件工具调用失败时标为 `TOOL_ERROR`，阻断该条件的正常结论。
8. 零结果时展示漏斗和约束最强条件；不得自动放宽阈值。
9. 解释只描述事实、规则匹配和未知项，禁止预测、承诺或直接交易指令。
10. 候选对比最多包含 3 个标的；同一指标只有来源、时点、单位和统计口径一致时才允许比较，否则标记 `NOT_COMPARABLE`。
11. 研究交接只输出可由 Evidence 推导的待核验问题和数据缺口；“下一步研究”不等于推荐、排序或买卖指令。

## 7. 状态与异常

`DRAFT -> PARSED -> ENTITY_RESOLVED -> NEEDS_CLARIFICATION -> READY_TO_CONFIRM -> CONFIRMED -> EXECUTING -> RESULT_READY`

任意阶段可进入：`AMBIGUOUS`、`UNSUPPORTED`、`INVALID`、`UNKNOWN`、`STALE`、`CONFLICT`、`DATA_ERROR`、`TOOL_ERROR`。  
从 `RESULT_READY` 输入修改后进入 `EDITING -> REVALIDATING -> READY_TO_CONFIRM`。取消修改返回原版本 `RESULT_READY`。

## 8. 非功能要求

| 维度 | 可验收要求 |
| --- | --- |
| 审计 | 随机抽取 20 个已执行版本，20 个均有 `strategy_id`、version、确认时间、execution_id、工具 request_id、as_of 与参数哈希 |
| 安全 | secrets 扫描对仓库默认分支的真实密钥命中数为 0；生产密钥只允许从服务端环境变量或 Secret Manager 读取 |
| 性能 | 50 次真实确认后执行中 P95 端到端时长不超过 60 秒；所有超过 10 秒的执行每 5 秒更新一次可见进度 |
| 可访问性 | 100% 状态同时包含文字；键盘可完成输入、确认、展开证据和关闭抽屉四项动作 |
| 合规 | 100 条红队提示中，预测、收益承诺、直接买卖建议输出次数为 0 |

## 9. MVP 验收

MVP 的最终验收以 `CFO_Review_and_Acceptance.md` 的 A01-A12 为准，必须全部通过。最低主链路标准为：

1. 20 名目标用户中至少 14 名在无人工提示下完成“输入 -> 确认 -> 结果 -> 证据 -> PE 改为 20 -> v2”。
2. 50 条预标注自然语言输入中，Intent、Universe 与 3 项 P0 条件的完全匹配次数至少 45 条。
3. 50 次真实的确认后执行中至少 47 次返回 `RESULT_READY`，P95 端到端时长不超过 60 秒。
4. 100 条随机条件判断的 Evidence 11 个必填字段完整率为 100%。
5. 10 类异常用例与 100 条合规红队提示均不得产生被伪装的正常结论、预测、收益承诺或直接买卖建议。
6. P95 单次成功执行可变成本不超过人民币 2.00 元，累计开发投入不超过 40 人工小时。

开发顺序受 `Business_Owner_Review_and_Revision.md` 的 G0-G3 阶段闸门约束。G0 未通过前，不得宣称真实数据主链路可用，也不得投入 iFinD 研究页和非必要 UI 扩展。
